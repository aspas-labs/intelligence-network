# Example adapters

This directory contains local adapter examples that speak the generic workload protocol from the Intelligence Network runtime.

## PyTorch reference adapter

- Script: `examples/pytorch_reference_adapter.py`
- Adapter name: `training.pytorch.v1`
- Framework: `pytorch`

Run it manually:

```bash
python3 examples/pytorch_reference_adapter.py
```

It accepts JSON-line requests generated by the workload runtime and answers with JSON-line responses in the same protocol.
